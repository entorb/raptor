# Raptor: Call of the Void

A web remake of the 1994 MS-DOS vertical shooter [Raptor: Call of the Shadows](https://en.wikipedia.org/wiki/Raptor:_Call_of_the_Shadows) (Cygnus Studios / Apogee / Scott Host). Moved theme to space and redrawn with modern procedural art and sound. Logic, weapons, enemy formations, and flight paths are ported 1:1 from the released [DOS source code](https://github.com/skynettx/raptor).

- Play in web browser or install as (PWA) app
- Play by keyboard on desktop or by touch on phone
  (for gamepad support use a tool like [AntiMicroX](https://github.com/AntiMicroX/antimicrox))
- Play at [entorb.net/raptor](https://entorb.net/raptor)

## Privacy

- All data on your device: no login, no database, no payment, no advertisement
- Anonymous usage stats are collected via global play counter and a local [Matomo](https://matomo.org/) instance

## Changes with respect to original game

- Moved theme form earth to space
- New graphics
- New sounds
- New easier first training wave
- Replay of each mission allowed
- No selling of basic weapon
- After mission accomplished: shield refilled to 50%
- Death and abort mission now earn 50% of credits
- Mission accomplished with 100% enemy kills: +10% credits bonus

## Development

```sh
pnpm install
pnpm dev          # http://localhost:5173/raptor/
pnpm test
./scripts/run_checks.sh
```

Game data (maps, enemy tables) is inspired from the shareware release. Graphics and sound are newly generated (no original assets are shipped):

```sh
# download FILE0000/0001.GLB from https://archive.org/download/RaptorCallOfTheShadows/raptor.ZIP
# to original_game/shareware/ (see original_game/README.md)
node original_game/scripts/extract-glb.mjs    # regenerates src/game/data/ep1.ts (+ original audio archive)
node scripts/gen-audio.mjs                    # regenerates public/assets/{sfx,music}
```

Review pages (dev server only): <http://localhost:5173/raptor/review/art.html> (all sprites, enemies grouped by mission) and <http://localhost:5173/raptor/review/sounds.html> (new sounds next to the archived originals).

See [AGENTS.md](AGENTS.md), [original_game/docs/dos_src.md](original_game/docs/dos_src.md) and [original_game/docs/glb_format.md](original_game/docs/glb_format.md).

## Developer tools

Hidden god mode (dev builds only): press **G** during a mission to become invulnerable and receive 10,000,000 CR (press again to turn invulnerability off). It stays on for the following missions. Aborting the mission resets the money, as in the original.
