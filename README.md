# Raptor: Call of the Void

A web remake of the 1994 MS-DOS vertical shooter **Raptor: Call of the Shadows** (Cygnus Studios /
Apogee), moved to space and redrawn with modern procedural art. Enemy formations, flight paths,
weapons, shop and difficulty are ported 1:1 from the released DOS source code.

Play on desktop (keyboard) or on a phone in landscape (drag anywhere to steer, auto-fire).

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | Arrows / WASD | drag anywhere |
| Fire | Space / Ctrl | automatic |
| Next special weapon | Shift / Alt | SWAP button |
| Nova bomb | B / Enter | NOVA button |
| Pick a special weapon | 1..0, - | tap its icon at the bottom |
| Pause | P / Esc | pause button |

Hidden god mode: press **G** during a mission to become invulnerable and receive 10,000,000 CR (press
again to turn invulnerability off). It stays on for the following missions. Aborting the mission resets the money, as in the original.

## Development

```sh
pnpm install
pnpm dev          # http://localhost:5173/raptor/
pnpm test
./scripts/run_checks.sh
```

Game data (maps, enemy tables) is extracted from the shareware release. Graphics and sound are
newly generated from code (no original assets are shipped):

```sh
./original_game/scripts/get_shareware.sh      # downloads FILE0000/0001.GLB to original_game/shareware/
node original_game/scripts/extract-glb.mjs    # regenerates src/game/data/ep1.ts (+ original audio archive)
node scripts/gen-audio.mjs                    # regenerates public/assets/{sfx,music}
```

Review pages (dev server only): <http://localhost:5173/raptor/review/art.html> (all sprites,
enemies grouped by mission) and <http://localhost:5173/raptor/review/sounds.html> (new sounds next
to the archived originals).

See [AGENTS.md](AGENTS.md), [original_game/docs/dos_src.md](original_game/docs/dos_src.md) and
[original_game/docs/glb_format.md](original_game/docs/glb_format.md).
